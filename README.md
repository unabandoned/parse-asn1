> A maintained fork of [crypto-browserify/parse-asn1](https://github.com/crypto-browserify/parse-asn1),

> [`@unabandoned/parse-asn1`](https://www.npmjs.com/package/@unabandoned/parse-asn1);
> the API is unchanged from upstream.
